নতুন ছবি যোগ করার সহজ নিয়ম (মোবাইল থেকে)

একবার index.html এবং gallery.js আপডেট করে GitHub-এ আপলোড করে দিলেই পরের বার শুধু এই কাজগুলি করবেন:

১) GitHub repository-র মূল ফোল্ডারে যান।
২) Add file → Upload files চাপুন।
৩) নতুন ছবি আপলোড করুন। যেমন: ganesh-puja-2026.jpg
৪) Commit changes করুন।
৫) gallery.js ফাইল খুলে Edit (পেন্সিল) চাপুন। photos তালিকার মধ্যে নতুন লাইন যোগ করুন:
   { src: "ganesh-puja-2026.jpg", caption: "গণেশ পুজো ২০২৬" },
৬) Save/Commit changes করুন। Netlify নিজে থেকেই সাইট আপডেট করবে।

একাধিক ছবির উদাহরণ:
const photos = [
  { src: "logo.jpg", caption: "আশুই ত্রিনেত্র সেবা সংঘ" },
  { src: "bookmark.png", caption: "কমিটির প্রতীক" },
  { src: "ganesh-puja-2026.jpg", caption: "গণেশ পুজো ২০২৬" },
  { src: "sandhya-arati.jpg", caption: "সন্ধ্যার আরতি" },
];

খেয়াল রাখবেন: ছবির নাম এবং gallery.js-এ লেখা নাম হুবহু এক হতে হবে। নতুন লাইনের শেষে কমা দিন। photos তালিকার শেষ ছবির লাইনে কমা থাকলেও সমস্যা নেই। শুধু ছবি আপলোড করলেই গ্যালারিতে আসবে না—gallery.js-এ তার নামও যোগ করতে হবে।
